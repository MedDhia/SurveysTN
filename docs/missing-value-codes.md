# Non-substantive response codes

Generated by `scripts/build_missing_codes.py` from the committed codebooks.

None of these are declared missing in the source files, so they survive into
every format in this repository as ordinary values. Recode them before you
compute anything. The codes differ by wave and, within a wave, by the width of
the variable's scale, so check the variable in `codebook.csv` rather than
applying one rule to the whole file.

The table is matched on label text, so it can catch a substantive answer that
happens to contain one of the words -- Wave IV's "Palestinians would refuse" is
an answer, not a non-response. Check the variable before recoding.
